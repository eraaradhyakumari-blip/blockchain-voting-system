# 🗳️ Blockchain Voting System

A secure and transparent Blockchain Voting System built using **HTML, CSS, and JavaScript**. The project demonstrates how blockchain concepts can be applied to create a tamper-proof and trustworthy digital voting platform.

---

## 📌 Project Overview

Traditional voting systems are vulnerable to fraud, vote tampering, and lack of transparency. This project solves these issues by recording votes securely using blockchain principles, ensuring that every vote is immutable and verifiable.

---

## ✨ Features

- 🔐 Secure voter registration
- 🗳️ One Person, One Vote
- ⛓️ Blockchain-based vote recording
- 📊 Live vote counting
- 📱 Responsive user interface
- ✔️ Prevents duplicate voting
- 🔍 Transparent election results

## 🚀 How to Run

1. Clone this repository.

```bash
git clone https://github.com/your-username/blockchain-voting-system.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. Register a voter and cast your vote.
